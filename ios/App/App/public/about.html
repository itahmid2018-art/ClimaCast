About ClimaCast

ClimaCast: Know your weather before it knows you.

Get hyper‑local, minute‑by‑minute forecasts powered by AI, with clear alerts and smart recommendations for every part of your day — from commute to workouts to weekend plans.

🌤️

Weather data provided with high precision by Open-Meteo

ClimaCast relies on Open-Meteo's open-source meteorological APIs for high-resolution numerical weather predictions (NWP), seamless global geocoding, solar radiation arcs, and comprehensive air quality forecasts (CAMS & GFS). All atmospheric datasets are rendered with zero commercial lock-in under the Attribution 4.0 International license (CC BY 4.0).

📱 App Description

Plan your day with confidence, not guesswork, ClimaCast turns complex meteorological data into simple, actionable insights so you always know what to wear, when to leave, and how to stay safe.

Built on reference‑grade data and modern design, ClimaCast delivers ultra‑fast, accurate forecasts across web and mobile—so you spend less time refreshing and more time living.

✨ Key Platform Features

🎨

Dynamic Weather Atmospheres

Immersive, CSS-based atmospheric gradients that smoothly transition based on real-time weather codes (Clear, Rain, Storms, Fog, Snow) and solar day/night cycles.

🤖

Gemini AI Weather Insights

Conversational natural-language summaries, "What to Wear" dressing advice, outdoor activity scoring, and a prominent "Tip of the Day" powered by Google's Gemini Flash SDK.

🍃

Multi-Source Air Quality (AQI)

Toggle between real-time AQI providers: Default Open-Meteo model and HyperLocal AQI via PurpleAir's real-time community optical sensor network.

⚡

Severe Storm Warnings & Alerts

Evaluates Open-Meteo convective models for severe thunderstorms, damaging gusts, hail risk, flash flooding, and air quality advisories with safety protocols.

🗺️

Interactive Radar & Cloud Map

Geospatial Doppler radar and infrared satellite cloud cover layers with a timeline loop player, opacity sliders, and theme-adaptive base maps.

🌓

Astronomical Moon & Dawn Pulse

Live synodic lunar calculation displaying moon phase, illumination percentage, and dynamic golden dawn aura with silent Web Notifications before sunrise.

⏰

Native Alarm Synchronization

Deep integration with Android Clock alarms, iOS Calendar/Reminders alarms (.ics with VALARM), and background Service Worker alerts.

📦

Offline Cache & Background Sync

Automatic client-side caching of weather data in CacheStorage via the Web Background Sync API, ensuring instant offline access with reconnect synchronization.

📌

Sticky Jitter-Free Header

Collapses smoothly into a persistent single-row header retaining the logo and search bar on scroll with dual-threshold hysteresis and GPU acceleration.

🛠️ Technical Architecture & Stack

Frontend Framework React 19 + TypeScript (Strict Type Checking)
Build Tool & Dev Server Vite 6 with Hot Module Replacement & Express backend
Styling & UI Tokens Tailwind CSS v4 + Plus Jakarta Sans Typography
Iconography & Motion Lucide React Icons + Motion (Framer Motion)
Primary Data Source Open-Meteo (Forecast, Geocoding, Solar & Air Quality APIs)
Artificial Intelligence Google Gemini 3.8 Flash via server-side @google/genai SDK
Cross-Platform Mobile Capacitor 6 (Android & iOS Native Wrappers)
Browser Extension Google Chrome Extension Manifest V3 (Unpacked & Web Store Ready)
Offline Persistence PWA Service Worker + Web CacheStorage + LocalStorage

📲 Cross-Platform Deployment

📱

Progressive Web App (PWA)

Installable directly to home screens on iOS Safari and Android Chrome via standard manifest.json and standalone display mode.

🤖

Native Android (Capacitor)

Configured with capacitor.config.json to compile into release APKs and Google Play App Bundles via Android Studio.

🍏

Native iOS (Capacitor)

Generates native Xcode project targets for iPhone and iPad simulators and App Store testflight deployment.

🧩

Google Chrome Add-on

Packed with Manifest V3 specification in public/chrome-extension/manifest.json for 1-click toolbar popup weather forecasting.
